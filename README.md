# Bracket Brain

A free daily college basketball guessing game. Each day there is one mystery
player and one mystery program. Guess using color-coded comparison clues.

## Features (planned)
- Daily player puzzle (school, conference, position, class year, height, home state)
- Daily program puzzle (conference, mascot, arena, tournament history, titles)
- Easy and hard days
- Hints that lower your score
- Win streaks and a shareable result grid

## Tech
Python, Flask, JSON/CSV data file, GitHub
